# CLASSIFICATION OF SCRIPTS DIRECTORY

Этот файл описывает назначение и статус всех файлов в каталоге `/scripts/`.

## ACTIVE (Используется в CI/CD или сборке)
* **`optimize-assets.js`**: Основной скрипт оптимизации ассетов и копирования атласов. Вызывается при запуске `npm run build` и `npm run optimize`.
  * **Владелец**: @Motaro900 / QA Team
  * **Статус**: Критический.
* **`generate-items-atlas.js`**: Скрипт сборки WebP-атласов оружия из исходников Free Texture Packer.
  * **Владелец**: @Motaro900 / Asset Pipeline
  * **Статус**: Критический.
* **`test-proxy-endpoints.js`**: Скрипт автоматического тестирования проксирования и подписей ручек API.
  * **Владелец**: @Motaro900 / Backend Team
  * **Статус**: Стабильный.
* **`audit-dependencies.js`**: Скрипт статического анализа импортов для верификации изоляции слоев (src, api, server).
  * **Владелец**: @Motaro900 / Backend Team
  * **Статус**: Стабильный.
* **`validate-bus-message.js`**: Скрипт валидации JSON-сообщений шины данных оркестратора AI-студии.
  * **Владелец**: @Motaro900 / Backend Team
  * **Статус**: Стабильный.
* **`add-decision-log.js`**: Скрипт валидации и добавления записей в историю принятия решений docs/reports/decision_log.json.
  * **Владелец**: @Motaro900 / Backend Team
  * **Статус**: Стабильный.
* **`assess-task-risk.js`**: Скрипт автоматического анализа уровня риска задачи и динамического выбора необходимых агентов для её решения.
  * **Владелец**: @Motaro900 / Backend Team
  * **Статус**: Стабильный.
* **`run-orchestration.js`**: Центральный исполняемый скрипт оркестратора AI-студии (Adaptive Intelligence Layer). Координирует оценку рисков, дискуссии саб-агентов, валидацию сообщений, анти-конфликтное разрешение и логирование.
  * **Владелец**: @Motaro900 / Orchestration Team
  * **Статус**: Стабильный.
* **`run-autonomous-qa.js`**: Исполняемый скрипт автономного QA-координатора (Stage 4). Оркестрирует запуск Vite, выполнение Puppeteer smoke-тестов, транслирует их консольный вывод агентам и применяет матрицу анти-конфликтов.
  * **Владелец**: @Motaro900 / Orchestration Team
  * **Статус**: Стабильный.
* **`run-gameplay-playtest.js`**: Исполняемый скрипт автономного геймплейного плейтестера (Stage 5). Инициализирует состояние, эмулирует 20 циклов игры (бой, покупки, улучшения, экипировка) и отсылает отчет о балансе и стабильности ИИ-агентам.
  * **Владелец**: @Motaro900 / Orchestration Team
  * **Статус**: Стабильный.
* **`optimize-weapon-balance.js`**: Исполняемый скрипт автоматического балансировщика оружия (Stage 6). Проводит быстрые симуляции боя (Monte Carlo), калибрует attackBonus оружия под целевой винрейт и перезаписывает исходный код конфигурации weapons.ts.
  * **Владелец**: @Motaro900 / Orchestration Team
  * **Статус**: Стабильный.

## OBSOLETE (Не используется в текущих пайплайнах)
Все перечисленные файлы не вызываются из `package.json`, CI/CD или других скриптов сборки и перемещены в `/.archive/scripts/` для сохранения истории:
* `check_images.js` (утилита проверки картинок)
* `cluster-sprites.js` (устаревший скрипт группировки спрайтов)
* `content_generator.js` / `content_generator.cjs` (генератор контента)
* `create_xp_potions.js` (утилита генерации зелий)
* `distribute_and_optimize.js` (устаревший оптимизатор)
* `distribute_images.js` / `distribute_reproduced_images.js` (скрипты раздачи)
* `optimize-sprites.js` (устаревший оптимизатор спрайтов)
* `process-wolf.mjs` (скрипт обработки ассетов волка)
* `validate-sprites.mjs` (валидация спрайтов)
