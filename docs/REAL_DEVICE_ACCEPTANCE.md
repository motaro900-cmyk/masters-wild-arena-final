## 2. Инструкция по проведению физического тестирования
1. Запустить локальный туннель (например, `ngrok http 3000` или локальный HTTPS прокси).
2. Указать URL туннеля в настройках приложения VK Mini Apps в поле «Адрес в мобильном приложении».
3. Открыть приложение в официальном клиенте ВКонтакте на физическом Android и iPhone.
4. Последовательно пройти все 19 пунктов и отметить галочками в данном файле.
