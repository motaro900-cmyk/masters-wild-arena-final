# Аудит методов VK Bridge API (2026 год)

Все нативные интеграции в коде игры Masters of the Wild соответствуют актуальным спецификациям VK Bridge.

---

| API Метод VK Bridge | Место вызова в коде | Назначение | Статус соответствия (2026) |
|---------------------|---------------------|------------|:--------------------------:|
| **`VKWebAppInit`** | `VKBridge.ts` (строка 72) | Первичная инициализация библиотеки на старте | **✅ Актуален** |
| **`VKWebAppGetUserInfo`** | `VKBridge.ts` (строка 106) | Получение данных профиля (имя, аватар) для регистрации | **✅ Актуален** |
| **`VKWebAppAllowNotifications`** | `VKBridge.ts` (строка 127) | Запрос разрешения на отправку PUSH-уведомлений | **✅ Актуален** |
| **`VKWebAppShowInviteBox`** | `VKBridge.ts` (строка 144) | Вызов окна приглашения друзей в игру | **✅ Актуален** |
| **`VKWebAppShowNativeAds`** | `VKBridge.ts` (строки 167, 553) | Показ рекламы (Rewarded видео, Interstitial объявления) | **✅ Актуален** (соблюден 3-минутный кулдаун) |

## 🚫 Исключенные/Устаревшие методы
* **`VKWebAppShowWallPostBox`** — полностью удален. Вся публикация переведена на Истории (`VKWebAppShowStoryBox`).
* **Старые платежные вызовы** (`VKWebAppOpenPayForm` и др.) — удалены. Игры каталога обязаны использовать `VKWebAppShowOrderBox` с типом `item`.
