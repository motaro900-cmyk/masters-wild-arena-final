## 1. Технические требования платформы VK

| Требование VK | Статус реализации в коде | Статус проверки |
| :--- | :--- | :---: |
| **Инициализация VK Bridge** | Вызов `VKWebAppInit` в `src/utils/VKBridge.ts` при старте с безопасным таймаутом | ✅ **PASS** |
| **Обработка кнопки «Назад»** | Событие `VKWebAppGoBack` слушается в `GameHUD.tsx` и закрывает активные окна | ✅ **PASS** |
| **Криптографическая авторизация** | Сервер проверяет HMAC-SHA256 подпись параметров `vk_*` в `server/vkAuth.js` | ✅ **PASS** |
| **Поддержка безопасных зон (Safe Areas)** | Использование CSS `env(safe-area-inset-top)` в `SafeGameLayout.tsx` | ✅ **PASS** |
| **Адаптивность (Mobile / Desktop)** | Динамическое масштабирование Pixi канваса и UI под портрет/ландшафт | ✅ **PASS** |
| **Внешние ссылки** | Все ссылки открываются через `vk.com/away.php?to=` в `openExternalUrl()` | ✅ **PASS** |
| **Отказоустойчивость при отсутствии сети** | Оффлайн-кэш Zustand + LocalStorage, понятные уведомления о сбое сети | ✅ **PASS** |
| **Автономия от зарубежных CDN** | 0 запросов к Google Fonts, Firebase, Vercel; все ассеты на российском VPS | ✅ **PASS** |
