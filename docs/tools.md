# 🛠️ Справочник разработчика: Автоматизация и Правила (Developer Tooling & Agent Rules)

Данный документ описывает назначение служебных каталогов, конфигурационных правил и инструментов автоматизации в корневого каталоге проекта.

---

## 1. Назначение служебных папок

### 📂 `.agents/` (AI Agent Rules & Compliance)
Каталог содержит конфигурации и инструкции для ИИ-агентов (включая Antigravity), которые работают над кодом проекта.
* **`AGENTS.md`**: Главный свод проектных правил и ограничений (Code Protection Contract).
  * **Комплаенс VK Mini Apps**: Фиксирует правила работы с VK API, платежами (запрет отладочных Bypass путей в проде) и редиректами внешних ссылок.
  * **Защита ассетов**: Запрещает полную очистку каталога `/public/assets/` автоматическими скриптами и регламентирует инкрементальность сборки.
* **Зачем он в корне?** Это фиксированное системное имя, используемое ИИ-системой для автоматического обнаружения контекста проекта. Не подлежит удалению или перемещению.

### 📂 `scripts/` (Dev & Build Tooling)
Содержит проверенные скрипты автоматизации сборки, верификации и оптимизации.
* **`optimize-assets.js`**: Оптимизатор графики (атласы, WebP) и аудиофайлов перед релизом.
* **`generate-items-atlas.js`**: Сборщик WebP-атласов оружия из исходников.
* **`audit-dependencies.js`**: Статический анализатор импортов, проверяющий изоляцию слоев `/src/`, `/api/` и `/server/`.
* **`test-proxy-endpoints.js`**: Интеграционные тесты прокси-слоя API.
* **`CLASSIFICATION.md`**: Карта владения и статуса скриптов.

## 2. Интеграционные тесты

### 📄 `test-smoke.js` (Puppeteer Smoke Tests)
Сценарий автоматизированного сквозного тестирования интерфейса игры с помощью headless-браузера Puppeteer.
* **Что делает:**
  1. Эмулирует мобильное устройство (iPhone 16.6) с тач-интерфейсом.
  2. Переходит по разделам игры (Главное меню, Магазин, Арена, Профиль).
  3. Проверяет симуляцию обрыва сети во время боя (Network Offline) и корректный выход из неё.
  4. Тестирует защиту от двойного клика при покупках.
  5. Проводит быстрое переключение экранов на наличие утечек и зависаний.
  6. Логирует все ошибки консоли браузера.
* **Артефакты:** Все снимки экранов сохраняются строго в игнорируемый Git-каталог `docs/reports/screenshots/`.
* **Запуск тестов:**
  ```bash
  # Запуск в headless режиме (в фоне)
  npm run test:smoke

  # Запуск в visual режиме (с открытием окна Chrome)
  npm run test:smoke -- --headed
  ```
