# Архитектура проекта: Masters of the Wild

В данном документе описана высокоуровневая структура проекта, зоны ответственности модулей и интеграция технологий.

---

## 1. Папки и зоны ответственности

* `/src/engine` — Ядро игры на **Pixi.js**.
  * `core/` — Жизненный цикл сцен (`SceneManager`), менеджер экранов, инициализация Pixi Application.
  * `entities/` — Классы игровых объектов на сцене (`HeroUnit` для отрисовки бойцов, анимации ходьбы, атаки, получения урона).
  * `systems/` — Системы частиц, эффекты боя (`EffectsManager.ts`), расчет зума и тряски камеры.
* `/src/store` — Управление состоянием на **Zustand**.
  * Объединяет слайсы состояния в единый `useGameStore`.
  * `/store/slices/` — Отдельные слайсы (экономика, магазин, кузница, квесты).
* `/src/ui` — Пользовательский интерфейс на **React + Vanilla CSS**.
  * Компоненты окон (`BaseWindow`, `ShopScene`, `ForgeScreen`, `ClanWindow`).
  * CSS стили лежат непосредственно в `/src/index.css` и файлах в соответствующих UI папках.
* `/src/services` — Модули внешних интеграций.
  * `SyncService.ts` — Синхронизация данных с Cloud Firestore.
  * `AudioService.ts` — Проигрывание фоновой музыки и звуков (SFX) боя через Howler.js.
  * `VKBridge.ts` — Обёртка над VK Bridge SDK для авторизации, вызовов нативной рекламы и платежей.

---

## 2. Мост Pixi.js ➔ React
Поскольку в игре используется двухслойная архитектура (сложные боевые анимации на холсте Pixi.js и текстовые меню/окна на React):

* Холст Pixi.js рендерится внутри React-компонента `BattleCanvas.tsx` / `GameApp.ts`.
* Zustand выступает единым источником правды.
* Изменения в Zustand-сторе (например, переход на новый экран `activeScreen`) отслеживаются через подписки, передавая события в Pixi `SceneManager` для плавной смены сцен.
