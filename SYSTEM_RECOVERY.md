ГЛОБАЛЬНЫЙ ТЕХНИЧЕСКИЙ МАНИФЕСТ: РЕСТАВРАЦИЯ UI STUDIO IDE

Инструкция для Агента: «ВНИМАНИЕ! Проект 'Masters of the Wild' требует полного восстановления и стабилизации встроенного игрового редактора (UI Studio). Текущая версия сломана или неполная. Ты должен восстановить следующие модули, обеспечив их 100% интеграцию друг с другом».

1. ЯДРО СИСТЕМЫ И ГЛОБАЛЬНЫЙ СТЕЙТ (Zustand + Persistence)
Стор: Восстанови useDebugStore. Он должен управлять:
elements: Массив объектов { id, type, x, y, scale, rotation, alpha, tint, zIndex, isVisible, isLocked, text, bindingPath, slices[] }.
bones: Массив { id, name, parentId, position, rotation, length, constraints }.
animations: Сложная структура треков и ключевых кадров { time, value, easing }.
Undo/Redo: Обязательно внедри zundo для отмены любых действий в редакторе.
Dev Mode: Весь редактор должен рендериться только при import.meta.env.DEV и активироваться по F2.

2. МОДУЛЬ SPRITE SLICER & ASSET BROWSER
Slicer: Реализуй инструмент нарезки. Я загружаю один файл (например, атлас персонажа), выделяю области рамками, и эти области становятся отдельными PIXI.Texture, доступными для перетаскивания.
Library: Добавь вторую строку в AssetsBrowser с встроенными иконками (сердца, мечи, щиты) из внешних CDN (Game-icons.net / Twemoji).
Drag-to-Stage: Реализуй бесшовный перенос из браузера ассетов на канвас PixiJS с автоматическим созданием элемента в сторе.

3. СКЕЛЕТНЫЙ ДВИЖОК (SPINE-LIKE RIGGING)
Bones Tool: Реализуй визуальное создание костей. Клики по сцене должны создавать иерархию (Parent-Child).
Skinning: Позволь привязывать любой нарезанный спрайт к конкретной кости. Спрайт должен наследовать трансформации кости.
IK (Inverse Kinematics): Реализуй алгоритм FABRIK или CCD. Если я тяну за «кисть», «предплечье» и «плечо» должны сгибаться автоматически согласно иерархии.

4. ANIMATION TIMELINE & EASING ENGINE
Timeline UI: Нижняя панель с Playhead, списком анимируемых свойств и сеткой кадров.
Interpolation: Реализуй поддержку кривых Безье. Математика в utils/easing.ts должна включать: Linear, Elastic, Bounce, QuadIn/Out.
Live Preview: В режиме isPlaying Pixi-сцена должна обновлять все elements и bones на основе интерполяции кадров в реальном времени.

5. ИНТЕРФЕЙС РЕДАКТОРА (React HUD)
Inspector: Правая панель должна динамически меняться. Если выбран спрайт — настройки цвета и нарезки. Если кость — углы и IK. Если текст — шрифт и привязка данных (bindingPath).
Hierarchy: Левая панель с деревом объектов, группировкой и кнопками видимости/блокировки.
Alignment Tools: Кнопки для быстрого выравнивания выбранных объектов по осям.

6. ГЛОБАЛЬНЫЙ МОСТ (React-to-Pixi)
Sync Logic: Убедись, что изменения в React-инспекторе мгновенно отражаются на Pixi-спрайтах через zIndex, alpha и tint.
Pointer Events: Реализуй корректный проброс кликов. В режиме редактора панели HUD не должны «прокликиваться» насквозь, но пустое пространство должно позволять выделять объекты в Pixi.

7. ЭКСПОРТ И ИМПОРТ
JSON Schema: При сохранении (Ctrl+S) генерируй единый конфиг, включающий и расстановку HUD, и структуру костей, и все анимации.
Hotloading: При старте игра должна считывать этот конфиг и полностью восстанавливать сцену.
