# Шаблон добавления нового предмета

## Чеклист перед добавлением:
- [ ] Есть спрайт/изображение предмета (png, желательно 128x128)
- [ ] Определён уровень требования (1-80)
- [ ] Определена редкость (COMMON / RARE / EPIC / LEGENDARY / MYTHIC)
- [ ] Определена валюта (золото или кристаллы)
- [ ] Выбрана категория (WEAPONS / HELMETS / ARMOR / SHOULDERS / PANTS / BOOTS / SHIELDS)

## Правила определения цены:

### По редкости и валюте:
| Редкость   | Уровень | За Золото        | За Кристаллы |
|------------|---------|------------------|--------------|
| COMMON     | 1-9     | 1,000 - 5,000    | —            |
| RARE       | 10-20   | 8,000 - 25,000   | 150 - 300 💎 |
| EPIC       | 25-45   | 30,000 - 80,000  | 300 - 800 💎 |
| LEGENDARY  | 50-60   | —                | 800 - 3000 💎|
| MYTHIC     | 65-80   | —                | 3000 - 8000 💎|

### Правило чередования (для RARE и EPIC):
- Смотришь на существующие предметы той же категории того же уровня
- Если последний предмет был за золото — новый за кристаллы
- Если последний был за кристаллы — новый за золото

## Шаблон объекта (скопируй и заполни):

```javascript
{
  id: 'CATEGORY_name_descriptor',     // пример: 'weapon_sword_shadow'
  name: 'Название предмета',
  description: 'Краткое описание предмета и его особенностей',
  type: 'EQUIPMENT',
  subTab: 'WEAPONS',                  // WEAPONS / HELMETS / ARMOR / etc.
  rarity: 'EPIC',                     // COMMON/RARE/EPIC/LEGENDARY/MYTHIC
  requiredLevel: 30,                  // уровень персонажа для покупки
  
  // Цена — ТОЛЬКО ОДНО из двух:
  priceGold: 50000,                   // если за золото
  // priceGem: 500,                   // если за кристаллы
  
  // Статы предмета:
  stats: {
    attack: 0,
    defense: 0,
    health: 0,
    speed: 0,
    critChance: 0,
    critDamage: 0,
  },
  
  image: 'item_image_name.png',       // имя файла спрайта
}
```
