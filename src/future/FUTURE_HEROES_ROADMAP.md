# 🐾 Future Heroes Roadmap

Список персонажей, запланированных но не реализованных в полном объёме.
Взят из `ui/BeastsScreen.tsx` (удалён как мёртвый код).
Используй как ориентир при добавлении новых героев в `src/configs/HeroesConfig.ts`.

## Связанные файлы в src/future/

| Файл | Назначение |
|------|-----------|
| `HeroEquipmentManager.ts` | Визуальное наложение брони/оружия поверх спрайта героя в бою (PIXI-сокеты). Подключить когда будут готовы ассеты и снята блокировка `if (isPanda \|\| isRaccoon) return`. |
| `HeroUnitConfigs.ts` | Конфиги анкоров для сокетной системы экипировки (SLOT_CONFIG, getWeaponVisualConfig). |
| `ShadowServerService.ts` | Анти-чит: клиентская валидация результатов боя с записью в Firestore `securityLogs`. Подключить когда Cloud Functions будут задеплоены. |
| `HeroFactory.ts` | AI-пайплайн генерации персонажей: изображение → обработка → регистрация. Подключить API нейросети. |
| `GenerationPrompts.ts` | Промпты для AI-генерации (тело персонажа, оружие). |
| `SpriteProcessor.ts` | Постобработка AI-изображений: нормализация размеров, pivot-точки. |
